SMART INVENTORY v4

Offline Windows desktop inventory system.

New in v4:
- Chronological weighted-average COGS and profit
- AD + Nepali B.S. dual dates
- Dashboard financial snapshot and low-stock alerts
- Product stock ledger with chronological movement
- Global search
- Date-range sales reports
- Complete CSV export
- Excel workbook export (full workbook, purchases-only, sales-only)
- PDF invoice export for selected sales
- Cash/Credit sales with customer, paid amount, due date and receivables
- Automatic startup/close backups with 30-backup retention
- Restore backup
- Product autocomplete
- Vendor-wise and product-wise reports
- Local SQLite storage
- Creator page with bundled cat image

Run:
  python smart_inventory.py

Build Windows EXE:
  build_windows.bat
